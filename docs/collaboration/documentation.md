# Documentation

TTS uses a mix of Sphinx and MkDocs. Sphinx publishes API documentation generated from docstrings, while MkDocs publishes fully authored prose documentation. The shared maintenance contract for Markdown metadata, document maturity, progressive traversal, grooming, and context validation lives in [Documentation Maintenance](documentation_maintenance.md). Repository-specific documentation may add domain constraints while preserving that central baseline.
